# 01 玩法与外围系统

这份文档分两半：

- **第 1–3 节是这款游戏的核心玩法**：规则、胜负、技能、机关、局内表现。关卡和难度的做法在 `docs/02` 第 4–6 节。
- **第 4–7 节是底座自带的外围系统**：金币、生命、技能、星级、宝箱、签到、每日任务、转盘、收藏、每日挑战、连击、关卡类型、广告。规则代码在 `client/assets/scripts/core/meta/`（纯逻辑，有单测），数值全在 `client/assets/resources/config/economy.json`。**新游戏照用，只调数值**；要改规则先改这里，再改代码和测试，同一次提交。

## 0. 设计原则（同类休闲游戏的共识，底座的取舍都按这几条）

1. **一眼看懂**：规则一句话说得清，新手前三关不用读字。
2. **难在决策，不难在手速**：难度来自「先点哪个」的顺序，限时只给难关。
3. **输得明白**：失败时告诉玩家为什么输（站台堵死了 / 时间到了），并给一个看广告复活的机会。
4. **爽**：每次点击都有反馈（缩放、音效、震动），连击越高画面越热闹（第 4.10 节），过关有庆祝。动画不挡操作。
5. **节奏**：每 5 关一个难关、每 20 关一个超难关；难关之后接几个放松的。
6. **不逼氪**：金币按「不看广告不够用，看广告加倍」设计（第 6 节）；没有广告的平台照样能玩完。

## 1. 核心玩法

规则代码在 `client/assets/scripts/core/dig/`（`rules.ts` 规则、`level.ts` 关卡文件），测试 `client/tests/dig.test.ts`；文件怎么分见 `docs/02` 第 1 节。

品类是「点选上场、自动搬运的像素画消除」。我们自己的东西是**双层画**（上层挖开露出另一幅画）和**挖机装火车**的题材；名称、角色、图标、画面、关卡全部原创（CLAUDE.md 硬性约束 1）。

### 1.1 一句话规则

点车厢进站，同色的小挖机自动去挖拼豆画、装进车厢，装满发车；一层一层把画挖完就过关。玩家只做一件事：**决定下一节叫哪节车厢**。

### 1.2 场上有什么

| 东西 | 说明 |
|---|---|
| 料场 | 拼豆像素画。每层是一张 宽 × 高 的格子图，一格一颗豆、一种颜色，也可以空着；层从下往上叠（常规两层，上下各是一幅画）。四周留一圈空地给挖机走 |
| 车厢 | 有颜色和容量（要装多少颗）。每种颜色的车厢总容量 = 料场里这种颜色的豆数 |
| 待发线 | 几条轨道（常规 3 条），车厢在上面排队。**只能点每条最前面的一节**；后面的看得到颜色和容量 |
| 装车位 | 固定 5 个。进站的车厢停在这里，显示颜色和还差几颗 |
| 小挖机 | 车厢进站后开出来的同色挖机，来回挖豆、倒进自己的车厢。玩家不操作它 |

### 1.3 哪颗豆能挖

把每个位置上最高的那颗豆叫「顶豆」，只有顶豆可能被挖。一颗顶豆能挖，要求**挖机能从料场外面，沿着比它低的地方走到它旁边**：

- 它上下左右四个相邻位置里，至少有一个比它低（那个位置没有豆，或者只有更低层的豆）；
- 而且那个位置和料场外面连得通（一路上的位置都比它低）。在最外圈的豆直接算连通。

所以画是从外往里、从上往下被挖掉的；被同层的豆四面围住的、被上层压住的都挖不到。画中间封闭的空洞不算「外面」。

下层的豆在上面的豆被挖走之前**看不见颜色**（「透视」技能可以看）。

### 1.4 一次点击会发生什么

1. 点一节待发线最前面的车厢。有空装车位就进站，这条线后面的车厢往前挪；没有空位、点的不是最前面的、被锁着的，都点不动（给一个轻反馈，不算失败）。
2. 进站的车厢开始装：它的挖机去挖所有能挖的同色豆，每装一颗「还差几颗」减 1。
3. 每挖走一颗豆都可能让别的豆变成能挖的，站台上所有车厢跟着继续装，直到没有豆可装为止。
4. 两节同色的车厢都在站台时，**先进站的先装**。
5. 装满的车厢发车，腾出装车位。**没装满、又暂时没豆可挖的车厢不退回**，一直占着装车位，等豆露出来再接着装。

结果只取决于点击的先后顺序，和动画快慢、2 倍速无关：规则在点击的那一刻一次算完，返回事件列表，画面按事件慢慢播。动画没播完也可以接着叫车，只要画面上还有空着的装车位（上一节还没开走的位子不能用）；新叫的车厢的挖豆动画接在前面的后面播。

事件：`enter`（哪条线的第几节进了哪个装车位）、`dig`（第几轮、哪个装车位、挖走了哪些位置的豆、每个位置露出来的是什么）、`depart`（发车）、`slot`（装车位多了一个）、`win`、`lose`（带原因）。一轮：按这一轮开始时的局面，站台上每节车厢把挖得到的同色豆装上；挖走的豆让别的豆露出来，下一轮接着装，直到没有豆可装。同一轮里先挖离站台近的（靠下、靠中间）。画面上把一次 `dig` 里的豆按每斗 `bucket` 颗（`game_ui.json` 的 `dig.bucket`，初值 3）分给这节车厢的几台挖机去跑。

### 1.5 胜负

| 项 | 内容 |
|---|---|
| 胜利 | 料场的豆全部挖完（此时车厢也正好全部发走） |
| 失败：站台堵死 | 一次点击算完以后，没赢，而且没有任何一节车厢点得动（常见的是 5 个装车位全被没装满的车厢占着）。文案 `UI_LOSE_JAM` |
| 失败：时间到 | 只有限时的难关、超难关有。文案 `UI_LOSE_TIMEOUT` |
| 复活（每局一次，看广告） | 堵死：加 1 个临时装车位（`REVIVE_JAM`）；时间到：加 `levels.json` 的 `reviveSeconds` 秒（`REVIVE_CLOCK`，文案里写了 30 秒，改数要一起改） |
| 命中（连击） | 每发走一节车厢算一击（`hitCombo`）。连击的时间窗在第 4 步调数值时按发车的节奏重定（`combo.windowSeconds`） |
| 进度（顶栏左边） | 已发车厢 / 总车厢 |
| 星级 | 照底座：按用了几样道具算（`docs/01` 第 4.4 节） |
| 2 倍速 | 料场和装车位之间那一行最右边的开关（`×1` / `×2`），只加快动画；开着换关不重置 |

### 1.6 技能

三个，顺序 `skills.order = ["slot", "shunt", "xray"]`。

| 技能 | id | 效果 | 什么时候算没效果（不扣） | 解锁 |
|---|---|---|---|---|
| 加位 | `slot` | 这一局多 1 个装车位 | 这一局已经加过 | 第 4 关 |
| 调车 | `shunt` | 可以点一节不在最前面的车厢，让它直接进站 | 没有空装车位；没有后排车厢 | 第 8 关 |
| 透视 | `xray` | 下层的画整幅显示几秒 | 当前没有被盖住的豆 | 第 9 关 |

解锁那一关是强制教学，送 1 个：等玩家自己叫了第一节车、动画播完以后才压暗全屏教（一进关就教太突然）。「调车」点了技能键以后要再点一节后排的车厢才算用（这时才扣）；没点后排、或者再点一次技能键就取消。下一关安排成正好用得上（第 5 关是第一个难关）。只剩 1 个空装车位时技能栏出救场小手（底座已有，`game_ui.json` 的 `station`）。

### 1.7 机关

每次只新加一种；首发关是不会输的教学关，开局弹一句说明（`game_ui.json` 的 `tips`，文案 `TIP_*`），之后两三关单独练，再和旧机关组合。首发关写在配置里（`docs/02` 第 6 节），下面是初值。

| 机关 | 规则 | 首发 |
|---|---|---|
| 双层画 | 第 1.3 节。这款游戏的招牌 | 第 6 关 |
| 石块 | 占一格，挖不动，不算目标，也不会消失；它挡路、挡连通（按一颗永远在的豆算高度） | 第 13 关 |
| 硬豆 | 豆上写着 2：算 2 颗，要挖两斗，车厢也要装 2 颗的量；挖完第一斗数字变 1，还在原地 | 第 18 关 |
| 问号车厢 | 排队时只看得到容量，进站才显示颜色 | 第 24 关 |
| 锁车和钥匙 | 上锁的车厢到了最前面也点不动；钥匙压在某一颗豆上，那颗豆被挖走时解锁对应的车厢 | 第 30 关 |
| 连挂车厢 | 同一条待发线上相邻的两节连在一起，一点两节同时进站，要 2 个空装车位 | 第 37 关 |
| 三层画 | 再多一层 | 第 44 关 |

留给以后关卡包的（首版不做）：冰冻豆、礼物包装豆、会移动的待发线、迷雾、炸药桶。

## 2. 关卡与难度（给玩家的感受）

参数、生成、量法、扩展写在 `docs/02` 第 4–6 节，这里只写感受。

- **短**：普通关 40–90 秒，难关 2 分钟以内。画不会越做越大，后期靠机关组合和新画保持新鲜。
- **上手快**：前两关怎么点都能过；第 3 关学会「被围住的颜色挖不到，叫早了占位」。
- **难关来得早**：每 5 关一个难关（第 5 关就有），每 10 关一个超难关；从第 10 关起难关限时。很难的一关后面一定接一关轻松的。
- **新东西来得密**：前 45 关里平均每 6 关出现一样新东西（三个技能、七种机关），第 45–50 关开始组合。首版 100 关、5 章，第 51–100 关不加新机关。
- **难度不一直涨**：第 30 关左右到顶，之后在一个区间里起伏。
- **输得明白**：前 30 关的普通关，只要「只叫现在挖得到的颜色」就一定能过；要猜下层的情况只放在难关。连输几次自动降一档。

## 3. 局内表现

底座已有的（顶栏、技能栏、连击满屏、难关横幅、过关庆祝、提示圈、教学手指）见 `docs/09` 第 8 节，照用。料场在 `game/board.ts`，装车位、待发线、挖机在 `game/station.ts`，时长在 `game_ui.json` 的 `dig`。车厢、挖机、三个技能图标现在是代码画的占位图（`client/tools/art/proto.mjs`），正式美术在 M3 换。玩法自己要做的：

| 时机 | 表现 |
|---|---|
| 点车厢 | 按下缩一下 → 沿轨道滑进装车位 → 数字弹一下 → 挖机一台接一台开出来 |
| 点不动 | 车厢左右晃一下；装车位满时装车位一起闪一下 |
| 挖豆 | 挖机开到豆旁边，铲一斗（豆缩一下被铲走，掉一点碎屑），开回来倒进车厢，车厢里的豆堆高。几台挖机错开出发，连成一条不断的队 |
| 露出下层 | 上层的豆挖走，下面那格亮出颜色；整层挖完时第二幅画有一个亮相 |
| 没豆可挖 | 挖机停在车厢旁边等，车厢上出一个「等待」小标记，让玩家看得出它在占位 |
| 发车 | 鸣笛、冒烟、开走，弹「发车！×N」；装车位空出来 |
| 快堵死 | 只剩 1 个空装车位而且站台上没有车厢在装时，装车位区域发红提醒 |
| 过关 | 最后一节车开走，展示这一关挖出来的画（进收藏册） |

挖机怎么走只是表现：实际能不能挖全由第 1.3 节的格子规则决定，不做寻路和物理。同屏挖机数量有上限（按性能定），不影响规则。

## 4. 外围系统（底座自带）

每一项列出：规则、数值在哪、代码在哪。玩家看到的叫法以 `i18n/strings.csv` 为准。

### 4.1 金币

唯一的货币。来源：过关（`levelCoins` / 难关 `challengeCoins` / 超难关 `bossCoins`）、连击（`combo`）、首次三星（`stars.first3`）、宝箱、签到、转盘、任务、每日挑战、收藏重复卡换金币（`dupeCoins`）、商店看广告领（`freeCoin.amount` × 每天 `freeCoin.daily` 次）、结算看广告翻倍（`adCoinMultiplier`）。用途：买技能（`toolPrice`）、买命（`lives.buyOneCoins` / `refillCoins`）、每日挑战重试（`dailyChallenge.retryCoins`）、转盘（`wheel.coinCost` / `tenCost`）。顶栏最多显示 9999。代码：`core/meta/meta.ts`、`settle.ts`；界面花钱统一走 `ui/popups.ts` 的 `spend()`（不够自动弹「金币不足」）。

### 4.2 生命

开一局要有命；输了、走过步后中途离开扣 1 条（`lives.freeUntilLevel` 关以前不扣）。上限 `lives.max`，每 `lives.regenSeconds` 秒回 1 条，离线照样回。无限生命（秒数）期间不扣。补命：金币买 1 条 / 补满、看广告得 1 条（每天 `lives.adDaily` 次）。当天第一次过关送 `lives.firstWinUnlimitedSeconds` 秒无限生命。代码 `core/meta/lives.ts`，弹窗 `livesPopup()`。

### 4.3 技能（局内道具）

`skills.order` 列出有哪几个（示例：撤销 undo、提示 hint、洗牌 shuffle），每个在 `features.skill_<id>` 那一关解锁，解锁时送 `skills.grantOnUnlock` 个。用技能的顺序：前 `skills.freeAllUntil` 关全部免费（每种每关最多 `toolMaxFree` 次，`toolMaxFreeById` 可单独配）→ 到 `skills.freeLevelUntil` 关每关第一次免费 → 每天 `skills.freeDaily` 次免费 → 库存 → 没有就弹购买（金币 `toolPrice` 或看广告得一个）。第一次过了 `skills.gift.after` 关送礼包（已解锁的每种各 `gift.count` 个）。没效果时不扣（`flow.hasEffect` 返回提示文案）。代码 `core/meta/skills.ts`，效果在 `game/flow.ts` 的 `useSkill`。

### 4.4 星级

按这一关用了几样道具（技能 + 复活；强制教学那次不算）记星：一样没用 ★★★；不超过这种关的两星线 `stars.twoStarLine` ★★；超过 ★。第一次三星多送一份（`stars.first3`：金币、卡、技能）。选关页显示每关拿过的最好星数。代码 `core/meta/stars.ts`。

### 4.5 过关宝箱

每次有奖励的过关开一个：金币 / 技能 / 收藏卡按 `chest.normal` 的权重；难关稀有以上翻 `chest.challengeRareBoost` 倍；连续 `chest.pityAfter` 关没出卡，下一关必出一张没有的。收藏没开放前不出卡。代码 `core/meta/levelChest.ts`。

### 4.6 七日签到

第 `features.signin` 关开放。7 天一轮（`signInDays`：金币、转盘次数、技能、小宝箱、第 7 天大宝箱），一天一次，断签不清零；可看广告双倍。代码 `core/meta/signIn.ts`，弹窗 `pages/signin.ts`。

### 4.7 每日任务

第 `features.tasks` 关开放。每天 `tasks.count` 项：`tasks.fixed` 必有，其余从 `tasks.pool` 随机抽（功能没开放的、平台没有那项能力的不抽）。做完一项得积分；每日积分进度条上 `tasks.dayTiers` 几档宝箱，每周 `tasks.weekTiers` 几档。任务进度在 `game/flow.ts` 的 `endRun` 里记（输了、离开也算）；新加任务要加文案 `TASK_NAME_<ID>` 和图标（`pages/tasks.ts` 的 `TASK_ICON`）。代码 `core/meta/tasks.ts`。

### 4.8 转盘（抽奖宝箱）

第 `features.wheel` 关开放。次数：每天免费 `wheel.freePerDay`、当天首胜 +`firstWinSpins`、看广告每天 `adPerDay`、金币 `coinCost`；十连 `tenCost` 至少一张 `tenMinRarity`。奖品按 `wheel.prizes` 的权重；连续 `pityAfter` 次没出 `pityMinRarity` 以上，下一次必出。页面不展示概率，上架前按商店要求加公示（`docs/06`）。代码 `core/meta/wheel.ts`。

### 4.9 收藏

第 `features.album` 关开放。卡在 `config/cards.json`（id、中文备注、稀有度），图 `resources/card/<id>.png`，名字文案 `CARD_<ID>`。卡分几册（`album.books`：开放关、卡、集齐大奖），全部集齐领终极大奖（`album.final` + 金色头像框）。重复卡自动换金币。卡从宝箱、转盘、签到、任务宝箱、每日挑战、首次三星、连击（只在每日挑战）来。头像可以换成拥有的卡。代码 `core/meta/album.ts`、`cards.ts`。

### 4.10 连击

局内每次「命中」（示例：消掉一组）计一击，两击之间不超过 `combo.windowSeconds` 秒算连上。到 `combo.startAt` 起算，`combo.tiers` 四档（档位文案 `UI_COMBO_T1..4`），每击给金币（一关封顶 `maxCoinsPerLevel`），结算按最高连击再给 `bestBonus`。每日挑战里连到 `cardChance` 的击数有概率送卡。画面见 `docs/09` 第 8 节。代码 `core/meta/combo.ts`。

### 4.11 每日挑战

第 `features.daily` 关开放。每天一关（从玩家已打过的关里按日期轮换，`dailyChallenge.levelStep`），当天第一次免费（走了第一步才算），之后重试看广告或花 `retryCoins` 金币。过了领每日宝箱 `reward`；连续 `streakDays` 天领大宝箱 `streakReward`。不扣命、没有说明和教学。代码 `core/meta/dailyChallenge.ts`。

### 4.12 关卡类型、章节、功能开放

- 普通关、难关（每 `hardEvery` 关）、超难关（每 `bossEvery` 关），在 `config/levels.json`；样式在 `game/levelKind.ts`（顶栏小牌子、开局横幅、选关页颜色、开始键角标、结算页）。
- 章节（`economy.json` 的 `chapters`：id、第一关）：地图页一章一张卡，局内背景 `bg/chapter_<id>.jpg`，名字 `CHAPTER_<序号>`。
- 超过关卡总数后在后一半循环（`Meta.levelFile`），地图写「第 N 轮」。
- 功能开放关 `features`：签到、各技能、选关、收藏、转盘、任务、每日挑战。没开放的入口灰 + 锁 +「等级 N」，点进去是锁页。
- 同一关连输 `easeAfterFails` 次后降一档难度（示例：少一种图案）。

### 4.13 设置与存档

设置：音乐、音效、震动、语言（`docs/10` 第 8 节）、隐私政策、隐私选项。存档结构 `core/meta/save.ts` + `playerData.ts`：关键节点（过关、花钱、领奖）立即写本地；读档时版本不对就开新档、缺字段补默认值（开发期不写迁移）。

## 5. 外围系统的入口

| 入口 | 在哪 | 开放 |
|---|---|---|
| 签到、每日挑战、转盘 | 主页左列 | `features` |

| 个人资料 | 主页顶栏头像 | 一开始就有 |

## 6. 经济

金币按「不看广告不够用，看广告加倍」设计：活跃玩家一天挣的金币够买一两样道具，想多用就看广告（商店领金币、结算翻倍、道具直接看广告得）。动金币、价格、奖励前后都跑：

```bash
./run.sh eco-sim                 # 一天挣多少、花多少、看几次广告
./run.sh eco-sim --no-ads        # 没有广告的平台（微信开通流量主之前）
./run.sh eco-sim --win=0.5       # 难一点的游戏
```

## 7. 广告

总开关 `game.json` 的 `ads.enabled`；界面按 `hasCapability('ads')` 决定入口在不在、按 `adsAvailable()` 决定能不能点（拉不到广告时入口变灰或整行不出）。广告位在 `config/ads.json`：

| 广告位 | 类型 | 在哪 |
|---|---|---|
| `rv_double_coin` | 激励 | 结算翻倍 |
| `rv_revive` | 激励 | 复活 |
| `rv_daily_retry` | 激励 | 每日挑战重试 |
| `rv_free_coin` | 激励 | 商店领金币、金币不足 |
| `rv_tool` | 激励 | 技能没库存时看广告得一个 |
| `rv_wheel` | 激励 | 转盘多一次 |
| `rv_signin_double` | 激励 | 签到双倍 |
| `rv_life` | 激励 | 生命弹窗看广告得 1 条 |
| `int_level_end` | 插屏 | 结算关掉时，按 `ads.json` 的 `interstitial` 频控（第几关起、间隔秒数和关数、刚看过激励视频不弹） |
| `bn_result` | 横幅 | 结算页、暂停弹窗底部 |

激励视频统一走 `ui/popups.ts` 的 `watchAd(广告位)`，只有看完才发奖。调试平台弹模拟广告页（看完 / 中途关闭 / 加载失败）。
