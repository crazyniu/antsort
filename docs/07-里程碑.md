# 07 里程碑（模板）

新游戏从底座开工后的顺序和每阶段的验收标准。底座已经把外围系统、界面框架、打包跑通，所以里程碑主要围绕「玩法 → 内容 → 美术 → 上架」。GitHub 上每个里程碑一个 milestone，一件可独立验收的事一个 issue（`docs/05` 第 5 节）。日期开工时填。

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M0 开工 | `docs/00` 第 0、1 步：新仓库、改身份、`./run.sh check` 全绿；Mac 上 `./run.sh` 能打开底座的示例玩法 | 截图：主页、局内、商店在浏览器里跑起来 |
| M1 玩法 | `docs/01` 第 1–3 节写好并经用户确认；`core/<玩法>/` 规则 + 测试；场地；局内外壳接上（技能、失败原因、复活、任务计数） | `./run.sh check`、`level-verify` 通过；Mac 上试玩前 10 关；`./run.sh auto` 代打不报错 |
| M2 关卡与难度 | 关卡参数或关卡文件、难度曲线、难关 / 超难关、降档；（要精调的）机器人量具和难度调试页的各档 | 全部关卡可解；用户试玩难度曲线 |
| M3 美术 | 风格锚定；角色 / 卡面、图标、背景、加载页、应用图标；换掉 `docs/00` 第 5 步的全部占位图 | 每批总览图用户验收；`./run.sh check` 的图片压缩检查通过 |
| M4 数值与文案 | `economy.json` 调完（`eco-sim` 给用户看）；12 种语言文案、卡名、章节名；字体重裁 | 每种语言打开各页面一遍，0 处缩字 |
| M5 三端打包 | 微信（资源上云开发、开发者工具预览）、iOS（装到手机）、Android（APK 装到手机）；广告用测试位跑通 | 三端真机截图 |
| M6 上架 | `docs/06` 清单；真实广告位；商店文案和上架图；提审 | 三端审核通过 |

每阶段做完给用户看（截图直接发图），确认后再进下一阶段。界面和美术的验收以用户在真机或 Mac 上看过为准。
