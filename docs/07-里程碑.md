# 07 里程碑和剩余任务

这款游戏的开发顺序、每阶段的验收标准，和**现在还剩哪些事没做**。玩法规则在 `docs/01` 第 1–3 节。底座已经把外围系统、界面框架、打包跑通，所以里程碑主要围绕「玩法 → 关卡 → 内容和美术 → 上架」。GitHub 上每个里程碑一个 milestone，一件可独立验收的事一个 issue（`docs/05` 第 5 节）。

每阶段做完给用户看（截图直接发图），确认后再进下一阶段。界面和美术的验收以用户在真机或 Mac 上看过为准，画面以效果图 `art/raw/mock_game_page_v2/mock_a.png` 为准。

## 2. 剩余任务

按做的先后排。每一条是一件能单独验收的事。

### A0. 换成简洁版版式（用户 2026-11-22 定的效果图 H，`docs/01` 第 3 节）

| # | 事 | 说明 |
|---|---|---|
| A0.1 | 素材 | Codex 照 H 单独出：凸点豆、带盖立体方块、火车头和车厢、天桥、铁轨、铲子图标；不从效果图上抠 |
| A0.2 | 版式 | 纯色背景、画在上、铁轨和天桥、走道、托盘、排队区、四个技能键；去掉草地、小河、船、一圈路 |
| A0.3 | 小人路线 | 方块 → 走道 → 近的天桥 → 画；之后只在画和车厢之间来回；搬完的回方块 |
| A0.4 | 不站着等 | 掐着下一列停稳的时刻放慢回程；下一列紧跟进站；放豆位置错开 |
| A0.5 | 色板 | `PALETTE` 换成用户给的 15 色，两关样关的画重画 |
| A0.6 | 技能「铲子」 | 规则和单测（`docs/01` 第 1.6 节）、技能键、文案、表现 |

### A. 现在这一版还没验过的（M1 收尾；A0 做完以后在新版式上验）

| # | 事 | 说明 |
|---|---|---|
| A1 | 两关各完整打一遍到过关 | 新排版以后只验了开局、上船、几队同时搬、装车；过关展示、结算、下一关没走过 |
| A2 | 输一次、复活一次 | 堵死的提示、空位泛红、看广告复活 |
| A3 | 四个技能各用一次 | 加位、调队、磁铁、铲子；分别在第 4、8、16、24 关解锁，用 `./run.sh level N` 进 |
| A4 | `./run.sh auto` 代打两关不报错 | 机器人还没在新画面上跑过 |
| A5 | 真机上看 | 手机上小人、数字看不看得清；小人多的时候卡不卡（一关七八百颗豆，同时最多 120 个小人） |
| A6 | 微信版顶栏 | 加速键挨着右上角胶囊左边，没在微信开发者工具里看过 |
| A7 | 矮屏幕（16:9） | 竖着的空间不够时画会被缩得很小（一格十几个单位），要看效果，不行就给矮屏幕收一收排队区 |

### B. 机关（M2）

每个机关都是：规则写进 `core/dig/rules.ts` + 单测 → 关卡生成器和求解器认得它 → 局内表现 → 首发关的一句说明 → 一关样关给用户看。

| # | 事 | 首发关 | 说明 |
|---|---|---|---|
| B1 | 连体块 | 6 | 两块一起上场占 2 个位子；杆的素材；两条相邻的船 |
| B2 | 问号块 | 11 | 排到最前面才翻开；翻开的动画 |
| B3 | 锁和钥匙 | 13 | 钥匙挂在画里一颗豆上，搬走时飞去开锁；锁、钥匙的素材 |
| B4 | 云朵 | 17 | **等用户确认方案**（`docs/01` 第 1.7 节）。确认后：规则、单测、生成器给画配云、云的素材（Codex）、云团飘到小人手里的表现；换掉叠层画 |
| B5 | 教学 | 1–3、每个机关和技能的首发关 | 现在第 1 关只弹一张带星星的说明卡（星星是占位的）；要做成手指引着点，说明卡配这个机关的图 |

### C. 关卡与难度（M3）

| # | 事 | 说明 |
|---|---|---|
| C1 | 图库 | 前 50 关要 50 幅像素画。Codex 按题材一批批出（甜点、动物、玩具……），每幅过一遍 `import.ts`，**人眼看一遍配色**：自动转出来不好看的重画（第 2 关原来那张就是这么换掉的）。大小从 10×10 到 32×32 |
| C2 | 前 50 关 | 按 `docs/01` 第 2.1 节的排布表写 `specs.ts`、生成、`level-verify`。现在的两关是看效果用的大画，要换成排布表里的第 1、2 关 |
| C3 | 难度量具 | 「想清楚」机器人、画的四个量（`docs/02` 第 6 节）；每关的数据落在目标区间里 |
| C4 | 并入底座升级的代码 | `levels.json` 的 `pace`、`level-verify` 报每关估算时长 |
| C5 | 降档变体 | 连输几次自动降一档：只换队伍，画不变 |
| C6 | 难度调试页 | 底座的调试页接上这个玩法的各档 |

### D. 局内还差的功能

| # | 事 | 说明 |
|---|---|---|
| D1 | 加速时间 | 现在右上角的加速键是免费的开关。按 `docs/01` 第 1.5 节做成「加速时间」：第 9 关开放，开放那天送 5 分钟、每天送 3 分钟，用完看广告加 10 分钟；数值进 `economy.json`，广告位 `rv_speed` |

| D5 | 小人的影子、叠放 | 小人脚下加一小团影子；人挤的时候后面的人的脸会压在前面的人身上（现在所有身子一层、所有脸一层） |
