# 09 界面设计系统（配色、字体、部件、各页版式）

这一套界面是底座的定版（用户逐页验收过）。**做新游戏不重新设计版式**：主页、商城、地图、局内、设置、结算等页面的布局和组件照这里做，只换配色主题（可选）、插画和文案。改版式之前先问用户。

所有界面**由代码生成**（不拖 prefab、不用编辑器摆场景）：`ui/kit.ts` 提供部件，`ui/shell.ts` 管页面和页头，`ui/popup.ts` 管弹窗。页面代码只组合部件，**不直接画色块、不自己摆标题牌**。

## 1. 画布与坐标

| 项 | 值 |
|---|---|
| 设计分辨率 | 750 × 1334 竖屏，原点在屏幕中心、y 向上 |
| 适配 | 手机适配宽度（宽固定 750，长屏多出来的高度各页自己分）；比 750:1334 还宽的屏（平板、折叠屏、电脑上的小游戏窗口）改成适配高度（`Boot.ts` 按比例选） |
| 安全区 | `Screen.top` / `Screen.bottom` 已扣掉刘海、灵动岛、状态栏、手势条；所有页面按这两条排，不伸进安全区外 |
| 微信胶囊 | `Screen.cap` 不为空时，页头（返回键、标题、主页顶栏、局内顶栏）挪到胶囊那一行（`Screen.headY`，高 `Screen.headH`，右边只排到 `Screen.headRight`）；有页头的页面从 `Screen.headTop` 往下排 |
| 图片倍率 | 位图都是 3 倍图：显示尺寸 = 像素 / 3（`kit.RES`） |
| 调试 | 地址栏 `?notch=1` 模拟灵动岛和手势条，`?capsule=1` 再加微信胶囊 |
| 验证比例 | 16:9（短屏，加胶囊也要排得下）、19.5:9、21:9、4:3（平板） |

## 2. 配色

整套界面是**平面纯色**：没有渐变、高光、描边。凸起的部件只在下面压一道同色系的深色粗边（约部件高的 11%）。颜色在 `tools/art/flat_skin.py`（部件图）和 `ui/kit.ts`（字色）两处，换主题改这两处后重新生成部件图。

|---|---|---|---|
| 主行动（绿） | `#3CC62B` | `#268F1B` | 每屏唯一的主按钮：开始、下一关、领取、购买 |
| 次行动（蓝） | `#3F8DFF` | `#1E55C4` | 次按钮、图标键（返回、设置）、选关键 |

| 不可用（灰） | `#B4C0CF` | `#8894A8` | 没解锁、次数用完 |
| 标题牌、标签牌 | `#2B7BEF` | `#1A52BE` | 页标题、主页入口标签 |
| 蓝色的块 | `#3585F2` | `#1D58C2` | 商品卡、任务卡、册子卡、列表行 |

**字色自动取**：部件建出来时登记它的「墨色」（`kit.ts` 的 `PART_INK`），文字和白色图标按最近的祖先取色，页面代码不用分别写：

- 深色底 / 直接压在场景上：白字 + 深蓝描边（`#0B2A73`）+ 一道更深的硬投影。
- 白色容器、浅色格子：深藏青字 `#1F56B0`，不描边；白色图标染成蓝 `#3F8DFF`。
- 彩色部件（按钮、蓝块、标题牌）：白字不描边，下面压一道和部件下边同色的实色。
- 代码里写 `COLOR.white` = 当前面的正文色，`COLOR.yellow` = 强调色（浅底上自动换成深琥珀 `#D98200`）。

## 3. 字

| 规则 | 值 |
|---|---|
| 字体 | 荆南麦圆体（OFL，`client/licenses/`），裁成只含文案用到的字，放 `assets/boot/game.ttf`（打进安装包，微信上从网上下的 TTF 会注册失败）；韩文另用资源圆体韩文版 `resources/font/game_ko.ttf`。新增文案后 `./run.sh font-subset` |
| 字号 | 主页「开始」66；主按钮 40～56；页标题 43（标题牌高 76）；标签、入口 24～26；正文不小于 28；最小 20 |
| 描边 | 约字号的 1/18；投影约 1/26 |
| 摆正 | 汉字和单词不倾斜、不旋转、不用斜体；只有纯数字允许 ±4° |
| 数字 | 不加千分位逗号；顶栏金币最多显示 9999（`fmtCoins`） |
| 清晰 | 按钮字按 2 倍渲染再缩回去（`text(..., { sharp: 2 })`，`button()` 已经这么做） |
| 不出框 | 字不许比底板宽：`button()`、`capsule()` 自动缩字；单行用 `fit()`，左右两段用 `fitPair()`。但**同一类字字号固定，放不下就改短文案**（`fit()` 只是保险，调试构建里每次缩字记进 `gsDebug.fitLog`，提交前应为空） |
| 文案 | 全部 `tr('KEY')`；按钮最多 4 个字，只写结果和代价（「+1」「双倍」「复活」） |

## 4. 部件（`ui/kit.ts`）

| 部件 | 函数 | 说明 |
|---|---|---|
| 空节点 | `box(name, parent, w, h)`、`at(n, x, y)`、`size()` | 一切从这里开始 |
| 图片 | `img(parent, key, w?, h?)` | key 如 `icon/coin`、`card/c01`、`kit/ic_gear`；没读好的图先占位、读到再显示 |
| 大图 | `lazyImg(parent, key, w, h?)` | 背景：先建节点，读到再显示，读不下来自动退避重试 |
| 九宫格 | `slice(parent, 'kit/panel_glass' \| 'kit/panel_blue' \| 'kit/row' \| 'kit/slot' …, w, h)` | 白容器、蓝块、浅格、暂存格 |
| 三宫格牌 | `plate(parent, 'skin/f_plate_blue' \| 'skin/f_dock' \| 'skin/f_hud' …, w, h)` | 按高度缩放、中间横向拉伸，圆角不变形 |
| 纯色块 | `tint(parent, w, h, color)` | 只用于遮罩、压暗 |
| 文字 | `text(parent, s, size, { color, outline, align, width, sharp })` | 颜色按面自动取 |
| 按钮 | `button(parent, { color: 'green'\|'blue'\|'yellow'\|'red'\|'gray', w, h, label, icon, onTap })` | 返回 `Btn`：`setLabel / setColor / setEnabled`。按下缩 0.96 并压暗 |
| 两行按钮 | `twoLines(btn, 主文字, 小字, 小图标)` | 如「购买 / 金币 100」 |
| 图标键 | `keyButton(parent, 'blue'\|'green'\|'red', glyph, size, fn)`、`iconButton()` | 返回、设置、关闭、加号 |
| 信息条 | `capsule(parent, w, h, icon, s, size, skin, widest)` | 金币、生命、进度；`widest` 按最长写法定宽，内容变了不跳 |
| 进度条 | `progressBar(parent, w, h, 'green'\|'yellow'\|'blue')` | `set(0..1)` |
| 红点 | `redDot(parent, x, y)` | 有东西可领 |
| 艺术数字 | `artNumber(node, '×12', h)` | 连击数字（图 `skin/j_dg_*`） |
| 页标题牌 | `pageTitle(parent, s)` | 一般不直接用，走 `pageHead()` |
| 点击 | `onTap(node, fn, { press, sound })` | 按下缩放、手指滑动不算点、带点击音 |
| 特效小图 | `fxImg()` / `recycleFx()` | 火花、光点走对象池 |

图标（白色平面图标，放在键和按钮上）：`kit/ic_back` `ic_x` `ic_plus` `ic_gear` `ic_video` `ic_check` `ic_music` `ic_sound` `ic_vibrate` `ic_globe` `ic_timer` `ic_lock`。

动画（`ui/fx.ts`）：`popIn` 弹出、`fadeIn`、`breathe` 呼吸、`wiggle` 晃、`bob` 上下浮、`shake`、`trauma` 震屏、`punch` 顿一下、`squash`、`flyArc` 弧线飞、`countUp` 数字滚、`cannon` / `confetti` 彩纸、`sparkle` 火花、`ring` 冲击波、`rayBurst` 放射光、`glowPop` 柔光、`flash` 闪屏、`floatUp` 飘字、`delay`。进场用 `shell.enterStagger(nodes)`（依次弹出，总时长 ≤ 0.8 秒）。

## 5. 外壳（`ui/shell.ts`）

- **没有底栏**。主页是根页面，别的页面都从主页点进去，左上角返回；`ui.go(name, arg)` 切页并记历史，`ui.back()` 照历史往回走，回到主页历史清空。要去的页面已经在历史里（局内 → 结算 → 下一关）就退回那一层。
- **按关开放的页面**（`PAGE_FEATURE`：收藏 album、任务 tasks、地图 levelSelect）没开放时 `go()` 自动换成锁页。
- **页面类**：继承 `Page`，实现 `build(root)`（只建一次）、`show(arg)`（每次进来）、`refresh()`（存档变了重画数字和红点）、`hide()`、`back()`。`topBar = true` 的页面才有主页顶栏（只有主页）。在 `Boot.ts` 里 `ui.register('名字', () => new XxxPage())`。
- **子页面页头** `pageHead(parent, 标题, { coins?: true, onBack? })`：左上蓝色返回键（88，微信 76）、标题牌居中（高 76、字 43）；要花金币的页面右上加一条金币（半透明深蓝 + 白字，按「9999」定宽）。内容从 `headBottom(有没有金币)` 往下排，页底留 `PAGE_BOTTOM`（24）+ 安全区。
- **提示条** `ui.toast(文字)`：屏幕中间偏上，1.6 秒消失。**全屏挡操作** `ui.busy(true/false)`：看广告、读关卡时。
- **弹窗** `openPopup({ w, h, title, noClose, tapOutside, onClose })`：压暗背景 + 缩放回弹；白色圆角底板（圆角 42），蓝色标题牌骑在上沿正中，右上红色关闭键压在板角；内容往 `p.body` 加，原点在板中心；最多两个主次按钮。有弹窗时局内暂停。

```

│ [头像] [🪙 9999  ＋] [❤ 5/5 12:30] [⚙] │ ← 顶栏（微信版在胶囊那一行，设置键挪到底部）
│                                 │
│ [签到]                    [商店] │ ← 左右各一列入口：112 的半透明白格子 + 90 的图标
│                                 │    + 124×40 的蓝标签牌骑在格子下沿
│ [每日]      ( 展示区 )     [收藏] │ ← 中间：下一关的拼豆画摆在一块米白底板上，下面停着小火车和两个小人（`home.ts` 的 `showPicture()`）
│                                 │
│ [转盘]                    [任务] │
│                                 │
│  ┌──────────────┐ ┌────┐        │
│  │   开 始       │ │选关 │        │ ← 绿色大按钮 430×156（两行：「开始」66 号 + 「第 N 关」30 号）
│  │  第 12 关     │ │ 🗺 │        │    右边 140 宽的蓝色选关键；微信版左边多一个设置键，开始窄到 390
│  └──────────────┘ └────┘        │
└───────────────────────────────┘
```

- **顶栏**：四块浮在场景上，没有整条底板——头像方块 92（点了开个人资料）｜金币小条（白底深蓝字，右端绿色加号，点了去商店）｜生命小条（回满前跟一个小号倒计时，点了开生命弹窗）｜设置键 84。两条小条平分头像和设置键之间的宽，金币略宽。
- **入口**：左列是「每天来点一下」的活动（签到、每日挑战、转盘），右列是常驻系统（商店、收藏、任务）。第一排格子顶离顶栏 82，两个入口间隔 36，长屏按比例拉开（最多 1.2 倍）。没开放：图标变灰 + 小锁，标签写「等级 N」，点了进锁页。有东西可领：右上红点，图标隔一会晃一下。
- **开始键**：难关、超难关时右上角压一块同色小牌子（火苗「困难」/ 闪电「超难」）。进场 0.6 秒后开始呼吸。
- **常驻动效**：展示区的光球上下浮、果冻般鼓扁、表面流光转；顶上日光呼吸、五束光柱摆动、地面光斑漂移、空中亮点闪；小光球从下往上冒。点光球会往上窜一下。换主题时这些可以删减，但「主页一直是活的」这一条要保留。
- **功能开放引导**：过关新开放的功能，回主页时弹「新功能」弹窗（大图标 + 放射光 +「去看看」），入口冒一圈冲击波并呼吸。

## 7. 子页面

所有子页面：全屏背景图（`lazyImg`）+ `pageHead()` + 内容。

**商城**（`pages/shop.ts`，有金币条）：技能卡两列排；技能是单数时，生命做成同样大的卡补在最后一格，「免费金币」（有广告时）在最下面占满一行；双数时生命和免费金币在最下面并排。卡片统一：左上名字、右上小字状态（拥有 N）、中间图标、下面按钮（绿色「🪙 价格」）。没解锁的技能换灰色锁定条和「第 N 关」。金币不够照常可点，点了弹「金币不足」（可看广告领金币）。

**地图**（`pages/map.ts`）：一眼看到所有章节。每章一张竖版蓝卡（330×470，两列，间隔 24×26）：章节背景当画面、上面章节名牌、下面「第 N–M 关」和进度条（过了几关 / 20）。没到的章节画面压暗变灰、中间一把锁、写「第 N 关解锁」；当前章贴「当前」小旗、整张卡轻轻呼吸。打开时滚到当前章那一行。点开进选关。

**选关**（`pages/levels.ts`）：一页一章，4 列 × 5 行圆形关卡点（格 158，点 122），左右滑动翻章。已过关蓝色 + 绿勾 + 拿过的星数，当前关绿色、呼吸 +「当前」，没到的灰色带锁；难关橙色 + 火苗、超难紫色 + 闪电。打开时停在当前关那一页。

**每日任务**（`pages/tasks.ts`）：顶部「每日 / 每周」分段切换；积分进度条上挂几档宝箱（够了亮、可领时跳动）；下面任务卡（蓝块）：图标 + 名字 + 进度条 + 「前往」/「领取」。

**每日挑战**（`pages/daily.ts`）：7 天连胜格子 + 今日宝箱预览 + 按钮三态：开始（今日免费）/ 再试一次（看广告 或 金币，两个按钮）/ 今日已完成（灰）。

**转盘 / 抽奖**（`pages/wheel.ts`，有金币条）：中间宝箱，周围飘几个装着奖品的光球（告诉玩家能开出什么）；剩几次的牌子贴在箱子下面；主按钮开箱，次按钮一排（看广告、金币开、十连）。开箱演出：光球被吸进宝箱 → 越来越快的蓄力鼓动 → 弹开闪白放射光 → 奖品升起亮相。页面上不展示概率；上架前按商店要求加概率公示（`docs/06`，概率可由 `Wheel.odds()` 算出）。

**收藏**（`pages/collect.ts`）：首页总进度 + 终极大奖宝箱，下面册子卡（两列）：进行中 / 集齐可领 / 已领 / 未开放。册内：顶部大奖条，卡片 3 列：白卡 + 卡面 + 名牌（稀有度颜色）；没有的卡是灰色剪影 + 「?」。

**锁页**（`pages/lock.ts`）：大图标 + 「第 N 关解锁」+ 解锁后能得到什么的预览 + 「去闯关」。

**签到**（`pages/signin.ts`，弹窗）：7 天格子，今天高亮（金色块），领过的打勾；「领取」+「看广告双倍」。

**个人资料**（`pages/profile.ts`，弹窗）：头像（点了从已有的收藏卡里挑）、昵称、当前关、最高连击、收藏进度。

- **技能键**：没解锁的整个不显示（图标不露），到解锁那一关才第一次出现；有库存写数量，免费写「免费」，没有了右上换绿色加号（点了弹购买：金币买 / 看广告得一个）。上场位快满时能救场的技能发光跳动，最对症的那个放一只小手。新技能解锁关第一次能用上时压暗全屏，只留这个键能点（强制教学）。
- **提示**：闲着不点几秒（前两关更短）自动在该点的东西上亮一圈；教学关再加手指。
- **连击满屏**（底座的，这款游戏不用，见 `docs/01` 第 1.5 节）：`startAt` 起算 → 连击计弹出，数字砸下来；每一击：档位色的柔光和冲击波、整个场面顿一下、四边光框闪；常驻：四边光框呼吸、背景放射光转、光点往上冒，档位越高越亮越快；升档：夸奖词（中文用艺术字图 `j_praise_1..4`，其它语言用字）从大砸下 + 全屏闪 + 放射光 + 两圈冲击波 + 震屏 + 两个下角喷彩纸，红档以上加烟花，停一下缩小飞进连击计；断连：数字变灰、抖一下往下掉、淡出（不出声）。
- **过关庆祝**：闪白、放射光、震屏、两角喷彩纸、四发烟花，1.2 秒后进结算。
- **难关横幅**：难关、超难关开局从左滑进一条横幅「困难关卡！过关 60 金币」，停一下缩成顶栏的小牌子飞过去；点场地马上收起。
- **暂停**（设置键）：和主页的设置是同一个弹窗（`settingsPopup('pause')`），多「回主页」「重试」两个按钮；走过步时离开要确认（会扣命）。

**结算**（`game/result.ts`）：横幅砸下 → 三颗星依次点亮（没拿到的灰）→ 金币数字滚动 → 宝箱晃动弹开亮出奖品 → 按钮出现，「下一关」呼吸；点任意处跳到最终状态；全程 ≤ 3 秒。从下往上：底部给 Banner 留 120 → 「主页」「翻倍（看广告）」一行 → 「下一关」大绿按钮 → 奖励条 → 宝箱 → 星级说明 → 横幅和星星贴顶。

**复活**（弹窗）：大图 + 按失败原因写效果（「撤回最后三块」「时间 +30 秒」）+ 琥珀色「看广告复活」+ 蓝色「放弃」。每关一次。没有广告直接失败。

**失败**（弹窗）：难过的图 + 原因 +「生命 −1」（扣了才写）+ 绿色「重试」+ 蓝色「回主页」。

## 9. 设置与通用弹窗（`ui/popups.ts`）

**设置 / 暂停** `settingsPopup('home' | 'pause')`：

```
        ┌─────[ 设置 ]──────┐(×)
        │ 🎵 音乐        [●━] │  ← 浅蓝行 556×96：图标 48 + 名字 32 号 + 开关 116×55
        │ 🔊 音效        [●━] │
        │ 📳 震动        [●━] │
        │ 🌐 语言   简体中文 > │  ← 点了弹语言列表（这一端带的语言，game.json 的 languages）
        │ [   隐私政策     ]   │  ← App 才有（hasCapability）
        │ [   隐私选项     ]   │  ← 需要时才有（欧洲 UMP）
        │ [   广告测试     ]   │  ← 调试构建
        │ [   难度调试     ]   │  ← 开发版
        │ [回主页]  [ 重试 ]   │  ← 只有暂停时
        └────────────────────┘
```

其它通用弹窗：`livesPopup()` 生命（四个一样大的选项：金币买 1 条、金币补满、看广告得 1 条、等待）、`needCoins(差多少)` 金币不足（看广告领金币）、`rewardPopup(奖品)` 恭喜获得（可带翻倍）、`revealCards(卡)` 新收藏卡翻面（稀有以上金光、彩纸、全屏闪）、`confirmLeave()` 离开确认、`giftPopup()` 礼包、`coinsFly()` 金币飞向顶栏并滚动、`watchAd(广告位)` 看激励视频（返回是否看完）、`spend(金币)` 花钱（不够自动弹金币不足）。

**加载页**（`ui/loading.ts`）：背景 + logo + 进度条 + 轮播小提示（`BOOT_TIP_*`）+ 版本号；微信版带健康游戏忠告。失败前 3 次悄悄重试，之后出「网络不太好」和「重试」，后台照样自动再试。

## 10. 审查清单

新页面、改版式后都过一遍（截图审查，`docs/08`）：

1. 3 秒内看得出主行动；全屏只有一个视觉最强的按钮，在下半屏拇指区，高度 ≥ 96。
2. 可点区域 ≥ 88×88；同级元素尺寸、间距、对齐一致。
3. 字 ≥ 20（正文 ≥ 28）；不倾斜；不出框；没有硬编码文案。
4. 顶部、底部避开安全区；微信胶囊那一行不压东西；16:9 短屏和 4:3 宽屏都排得下。
5. 各状态都有：默认、未解锁、有红点、加载中、出错、空。
6. 常驻动效不超过两处，不抢主按钮；进场 ≤ 0.8 秒；点击都有反馈。
7. 只用 `kit` 部件，没有框中框。
