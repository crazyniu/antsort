# 上架图出图需求

一个画面 × 一种语言一份：`<画面>_<语言>.txt`（如 `hero_en.txt`、`hero_zh_CN.txt`），`./store/gen.sh` 让 Codex 整张画（字也画在图里），出到 `art/raw/store/posters/`，再 `python3 tools/store/export.py` 等比缩放、裁成各商店尺寸放进 `store/images/`。每种尺寸 5 张；画完逐张看字有没有写错（`docs/10` 第 6 节）。

需求模板：

```
竖版手游宣传图，1320×2868。画面：<一句话场景，主角在做什么>。
顶部一行大标题：「<短标题，6 个字以内>」，字要大到手机商店缩略图上也看得清，粗圆体、白字深色描边。
风格：明亮、圆润、高饱和的卡通休闲风，参照附图（我们自己的图）的质感。
禁止：出现任何现有游戏的角色、界面、logo；不要真实游戏截图；不要小字。
```
